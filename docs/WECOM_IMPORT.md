# 从企业微信导入资料

## 经理怎么使用

进入「资料导入」，点击「从企业微信导入」。未连接时可直接在弹窗中绑定本人的企业微信；若账号仍使用演示密码，先到个人中心改密码。

1. 粘贴具体的微盘文件、在线文档、智能文档、智能表格或在线表格链接；也可按关键词搜索本人授权范围内的资料，最多一次勾选 10 份读取。分享链接里的 `scode` 分享码会忽略，可直接粘贴从企微复制出来的完整链接。
2. 等待读取完成。智能文档会逐页读取正文；表格先列出子表，必须明确选择本次读取的子表，仪表盘不当作业务记录。
3. 核对来源、正文摘录或字段及前五行样例，再点「确认保存到资料导入」。此时保存的是本次读取快照，还没有发布知识或写入台账。
4. 关闭弹窗，在「我的导入」继续核对知识分类或台账字段。外部资料默认仅本人可见，可在知识审核前明确选择其他范围。台账写入仍需要原有导入权限。
5. 如提示缺少某项功能权限，点击企业微信官方授权入口处理，再重新读取。仅绑定成功不能代替具体资料授权成功。
6. 搜索时如果命中幻灯片、收集表、思维导图、流程图、汇报等当前没有正文读取接口的类型，页面会说明「暂不支持自动读取」并给出数量，不会把这些结果显示成「没有搜到」；这类资料请先在企微导出为支持的文件再上传。

页面刷新后，可以重新打开入口查看本人近期读取记录。预览一小时过期；读取最长 15 分钟，超过上限请拆分资料。导入确认前会再次检查本人连接和源资料读取权限。预览期间文档版本或微盘修改时间变化时，要求重新读取。

## 接入范围

- 微盘离线文件：先读取基础信息，再通过官方下载接口获取原件，进入现有文件解析、审核或清洗流程。在线文档不会误用微盘二进制下载接口。
- 在线文档：读取 Markdown 正文，包括官方 CLI 返回到隔离目录的长正文；保留来源链接和版本信息。
- 智能文档：读取页面清单后逐页读取内容，保留页面标题和子页面正文。`doc.weixin.qq.com/smartpage/<docid>` 编辑态和 `page.weixin.qq.com/smartpage/p/<docid>` 发布态分享链接都可读取，发布态只读。文内的图片、附件、内嵌数据表不被伪称已下载；内嵌表应通过其智能表格链接单独接入。
- 智能表格：选择子表后分页读取完整字段和记录，保留原始字段类型、记录标识与复杂值的 JSON 快照，生成可供既有台账清洗使用的表格。
- 在线表格：读取工作簿返回的明确范围，分批取单元格和公式。遇到截断、无权限单元格或范围不完整时停止，不把不可见区域当空值。

附件、图片、关联、查找引用、公式等复杂列保留原始类型快照，未自动下载附件或展开关联；台账映射中必须忽略这些列。需要这些字段成为业务主键、金额或其他必要字段时，应先在源表整理为可核对的简单列，再重新读取。

子表或工作表在企微里没有名称、接口没有返回标题时，页面按顺序显示「未命名子表 1」等占位名，仍可核对字段和样例后接入；接口没有返回子表标识时直接报错，不会猜一个子表当完整数据。

## 缺少功能授权怎么办

个人连接绑定成功只代表扫码登录完成。读取正文、搜索文档、下载微盘原件还需要机器人在企业微信侧开通对应功能权限；未开通时页面给出 `40301` 提示和官方授权入口，不会把失败显示成「没有资料」。

- 机器人创建者：点击页面上的官方授权入口，按提示确认对应功能权限后重新读取。
- 其他人：需要机器人管理员或企业微信管理员在管理后台为该机器人开通「搜索与获取文档内容」「微盘文件读取」等权限。
- 开通后不需要重新扫码，回到弹窗重新读取即可。仍失败时以小聚或本页显示的实际回执为准，不要仅凭「已绑定」判断资料已入库。

读取上限为原件 50MB，表格 20000 行、200 列（在线表格另限 100 万单元格），智能文档 100 页。超过限制明确停止，不截取前几页冒充完整数据。

## 数据与权限

这是用户主动选择资料的一次性接入，不是全盘抓取或持续同步。后续源文档修改、删除或撤权不会自动删除已审核保存的副本；如需持续同步，需要另行设计版本合并、台账更新口径及撤权处理。

- 每次调用使用当前账号的个人 CLI 连接；请求中不能指定其他员工账号、凭证或任意文件路径。
- 只接受明确的企业微信官方资料链接，不由通用 HTTP 客户端抓取用户提供的任意 URL。
- 文件下载和大正文只允许从本次随机请求的本人隔离目录读取，读取后清理该目录。通用小聚 CLI 工具仍不能自由传入本机文件参数。
- 读取预览按账号、连接版本、密码与权限签名隔离，文件权限为 0600。连接或权限变化后，旧预览不能继续确认。
- 本次来源信息与原始类型快照挂接在 `ImportBatch.suggestion.external_source`，后台分类后仍保留。原始快照下载沿用该批资料的访问权限。
- 预览确认可重试，同一来源、同一内容的已存在快照复用本人原记录。台账再由原清洗服务提交时查重，不自动覆盖已有业务。
- 源资料内容仅作为数据，不会改变工具权限、共享范围或执行指令。

预览状态保存在 `STORAGE_DIR` 父目录下 `wecom-import/<user-id>/`，确认后副本归档到原文件存储。两者均随 `/data` 卷备份；本次无数据库结构变更。

`backend/tests/test_wecom_import.py` 使用与官方 schema 对应的合成回包，覆盖链接校验（含分享码、发布态智能文档）、逐页正文、分页完整性、源权限复核、本人工作目录、复杂字段阻止误映射、未命名子表占位、搜索命中不可读类型时如实告知、重复确认和跨账号隔离。`test_wecom_cli.py` 覆盖只读方法白名单、真实命令参数、本人配置目录及下载输出目录。

`acceptance/wecom-import.mjs` 配合 `acceptance/wecom-import-api.py` 验证桌面和手机 UI；测试 API 强制独立本机库及合成 CLI 标记，不能对生产数据库运行。合成测试不等同于所有经理已经完成企微功能授权。
