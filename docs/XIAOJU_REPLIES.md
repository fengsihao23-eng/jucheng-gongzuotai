# 小聚对话回复与界面

更新日期：2026-11-04。

参考 [OpenAI 的界面指南](https://developers.openai.com/plugins/concepts/ui-guidelines)和[当前对话交互说明](https://learn.chatgpt.com/docs/prompting)，小聚采用白底阅读区、浅灰用户气泡、紧凑的工作进度、独立文件卡片与底部输入框。

## 回复内容

- 先给结论或实际办理结果，再按需补充依据、明细和下一步。
- 合同、回款等同类记录优先使用表格，关键数量和金额适度加粗；简单问题保持短答。
- 支持标准 Markdown 标题、段落、嵌套列表、引用、链接、行内代码、代码块与表格。代码块有常用语言高亮。
- 表格可单独复制为制表符分隔的单元格，代码复制保留原始空白，整条回复复制保留原始 Markdown。
- 工作过程默认收起，展开可查看实际步骤；完成后自动收起。待确认、部分完成和失败状态不会显示成功勾选。
- 业务导出和工作区文件统一展示在回复下方，回执折叠时仍可下载，继续使用本人登录态和原有权限检查。
- 手机宽表格在自身区域内横向滚动；输入框支持中文输入法、Shift+Enter 换行、执行中补充要求与停止。

历史回复会使用新的界面渲染；结构化回复规则适用于后续生成的内容，不改写已保存的对话。

## 渲染边界

Markdown 原生 HTML 禁用，危险链接由解析器过滤。代码按文字转义，远程图片呈现为链接。界面不执行模型回复中的脚本或原生 HTML。执行单确认和业务权限规则沿用原有流程。
