# 小聚业务能力

小聚使用完整官方 Pi SDK 1.3.0 与 DeepSeek。员工在任意页面右上角打开「小聚」，直接描述目标即可调用现有工作台业务；也可切换历史对话、整理上下文、复制对话与工作文件，并在独立工作区处理文件和运行脚本。公司接入统一配置，员工无需填写企业密钥。

## 可以直接这样说

- “查一下我的待办审批。”
- “登记一个客服工单：南山学校的录播主机无法联网，渠道电话。”再说“把刚才那张工单改成排查中。”
- “生成今天的每日支出报表，给我下载。”
- “新增合同：客户南山学校，金额 12000 元，业务线 XY，签约日期 2026-10-20。”核对具体执行单后点击确认。
- 上传考勤 Excel 后说：“导入这份考勤，核对异常并生成汇总表。”
- 上传 Word 后说：“按招标要求检查这份标书，生成整改清单。”
- “查询我负责项目的延期节点，生成周进度。”

小聚先读取可用功能和参数，查询人员、项目、状态等真实选项，然后实际调用业务。缺少客户、日期等必需业务信息时，只询问缺项。历史对话与附件用于连续办理；确认后自动接着核对回执、完成剩余步骤。

## 覆盖范围

打开小聚右上角「能办什么」，可按模块或关键词查找当前账号能办的事。选中事项会先填入对话，可补充对象、日期和要求，再由本人发送。来源页面可用来缩小范围，小聚仍从业务接口核对项目、人员和记录。

当前静态目录包括 **334 个 API 动作、17 个 MCP 工具和 1 个附件预览，共 352 项**，覆盖 29 个工作台模块。企业微信个人连接按各账号实际授权另行列出。这些是查询、办理、导入和导出等接口动作，不代表 352 套独立流程或均已在真实外部环境联调。

- 运营项目可填写项目进度并从有日期的下一步工作创建负责人计划，也可查询进度、布置任务、提交自行安排、按权限审核和反馈。月度统计区分来源，已有事项继续在原任务办理。
- 财务可登记实际发票和到账、匹配和核销、办理更正、核对来源后入账；在确认前展示实际对象和变更。
- 企微可读取审批模板、发起报销与合同审批、查询客户联系和本人授权范围内的数据。接口中心通过已配置授权调用指定官方接口，并展示具体执行单；企微后台的接口和资源权限继续生效。
- 工作台内的合同、流水、项目、知识审核、考勤、客服、标书、资料导入和管理等，继续由原页面共用的服务处理。资料导入可预览，按用户明确决定准备执行单，并回读实际处理状态。

登录密码、令牌、扫码及个人授权保留在专用页面由本人处理。对话不会代替业务审核人的决定，也不能调用自己的确认入口。

## 业务执行与结果

查询、报表生成、可撤回的工单和节点更新等按用户指令直接完成。财务写入、删除、权限变更、外发通知等先显示目标记录、字段、附件、变更前内容及接收范围。执行单有效 30 分钟；仅登录本人能点击确认，模型无确认权限。汇报催交在准备执行单时固定具体人员和期间，后续新增人员不会自动加入接收范围。

每一步实际执行生成可核验回执。聊天可展开完整数据、查看业务页面、下载签名文件。展示的数据环境来自服务配置；当前演示模式会明确标记。确认后可继续整个工作流程；已有写入按账号、工作流程、功能及具体参数去重。写入结果不确定时要求先核实当前记录，避免自动重复提交。

文件按钮支持上传本人业务文件，最多 20 个、单文件 50MB。通过随机附件 ID 引用，模型无法指定任意服务器路径。预览支持 xlsx、docx、CSV/TSV、文本/Markdown；预览有行数与字数限制，完整导入仍走原模块解析器。PDF、图片、旧 xls 的直接预览未实现，不能声称已完成解析。格式是否可用于具体导入，以原业务模块能力为准。

## 权限与实现

- API 通过内部 ASGI 请求调用原业务路由，使用当前用户短时令牌，沿用原菜单、按钮、记录范围、业务校验和审计。MCP 调用原工具执行器，沿用注册表授权、限流和审计。
- 目录按菜单、按钮和 MCP 授权过滤。执行时再次读取账号与权限；员工不能通过聊天绕过原有权限。主机文件与 CLI 接入操作仍仅对管理员开放。
- 确认单绑定本人、具体参数、账号权限、数据源环境和变更前快照。权限/环境变化、记录被修改或执行单过期时拒绝执行。
- 任务、附件、执行单、回执保存在 `STORAGE_DIR` 父目录 `xiaoju/`，文件权限 `0600`。个人业务数据按账号隔离；权限变化后重新校验并隐藏历史结果。部署需与 `/data` 持久化卷一同备份。
- 新对话的文本和完整工具轨迹保存在本人服务端会话，支持跨刷新和进程恢复；模型 API Key 仅经 stdin 进入可信运行时，不写入会话。公司凭证通过独立接入入口保管。
- 原生文件与 Shell 工具只运行在当前对话的独立容器；容器不包含后端配置、数据库凭证、Docker socket 或其他员工文件，且不连接网络。业务数据仍经原权限执行器访问。凭证下载、确认路由、密码等不加入业务目录。

主要代码：`backend/app/services/xiaoju_business_catalog.py`（目录）、`xiaoju_business.py`（执行与确认）、`xiaoju_business_state.py`（隔离存储）、`xiaoju_service.py`（Pi 任务循环），以及前端独立页面 `views/Xiaoju.vue`（路由 `/xiaoju/:id?`，逻辑在 `composables/useXiaoju.js`，界面组件在 `views/xiaoju/`）和三个业务结果组件。

## 当前外部接入状态

本版本已让小聚执行**现有工作台**业务。真实公司数据与外部操作能否完成，还取决于原服务适配器与企业授权：

- 企业微信、乐享等需要管理员配置实际企业授权、可信域名及相应业务权限。
- 柠檬云目前能验证应用基础授权，现有财务适配器的业务路由仍需按实际账套官方 API 联调，当前保持演示模式。
- 未实现的业务、未授权的企业接口、原模块不支持的格式，不会因接入模型而自动可用。
- WorkBuddy 首次客户端导入仍需在客户端完成；网页不能自行读取员工个人电脑。
