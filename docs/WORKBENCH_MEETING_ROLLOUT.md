# 经营工作台与智慧校园试点

## 上线后入口

| 入口 | 能做什么 |
| --- | --- |
| 系统管理 → 账号与角色 | 默认展示企业通讯录，点实际部门打开人员小卡；可按角色筛选或搜索姓名，点员工查看实际菜单、操作、数据范围和最近登录。平台管理员可在同一张卡上保存个人角色；角色规则单独维护。全量人员表保留在「账号明细」。授权变更、任务作废/恢复需要本人重新登录后 15 分钟内完成；不共享高权限账号。 |
| 运营项目 → 项目团队、任务情况 | 单人维护或按部门多选增员。任务可设全项目组可见或指定成员可见；主负责人、发布人、指定审核人及项目管理者保留办理权限。普通成员可见范围一致用于列表、详情、汇总和通知。公司级全量只读权限为 `operations:view_all`；`operations:archive` 需单独授予，且仅能作废本人能管理的项目。 |
| 运营项目 → 学校采购 / 每日收入 / 市场开拓 | 采购直接进学校建设清单；每日收入支持逐笔登记和 CSV/XLSX 预览后导入；市场开拓按学校聚合指定类型的原任务。支持项目公共收入。 |
| 运营项目 → 项目与个人总结 | 按周/月选择期间，按当前权限自动从任务和历史反馈生成。未反馈单列；可点回原任务或复制总结。当前按归属读实时记录，不当作冻结的历史快照。 |
| 经营 → 合同台账 / 回款台账 | 合同的累计、本月、本周、今日卡片使用同一筛选口径下钻和导出。回款按到期年或签订年查看，旧款、本年、以后和无日期分组；可记录进展或定向催办、指定人员回复。 |
| 经营 → 商机信息 / 招标与在建 | 在商机详情可发起登记招标项目；也可直接登记，来源商机可追溯。原项目编号及详情链接继续使用。 |
| 市场与项目 → 重点项目 / 一般项目 / 历史项目 | 重点跟进显示本周是否反馈和节点日期，可暂停/恢复；日常非重点项目单列，结项项目进入历史。已验收及运维不自动算结项。 |
| 财务数据 → 源表核对 | 财务负责人登记真实企微表格/微盘 XLSX 和字段映射，以本人授权读样例。核对后可启用 17:20 定时只读。源表读取结果不直接登记开票、到账和核销。 |
| 系统管理 → 机器人授权续期 | 配置具体功能、实测到期日、负责人和替补；按日去重站内提醒。续期由负责人在企业微信操作。 |
| 运营项目 → 设备产品库 | 选学校、输入建设需求、选择授权产品与数量，生成可编辑方案及设备清单。报价/规格缺失明示待核对；可引用本人有权阅读的已发布知识库资料。 |

### 使用注意

- 企微派单和重新指派进入通知队列；当前通知任务每五分钟尝试投递一次。生产只发送给已绑定本企业且仍有任务访问权限的账号，企微消息不带任务详情。点击消息回工作台反馈，不接受聊天里一句“完成”直接改状态。
- 试用任务作废后保留原始反馈、节点和审核记录；“已作废任务”可查看和恢复。先用已核实的任务编号定位。发布不批量更改现有成员和角色。
- 学校收入模板四列依次为「学校」「实际收款日期」「收入金额」「备注」。源表先按一校一日合计、日期用实际收款日，金额单位为元。预览有冲突时更正源表或原记录，不能覆盖既有不同金额。
- 合同四栏只计入截至今日、未终止的签约，周一为周起点。回款以合同金额和截至今日的登记实收为准，按计划顺序分配；没有计划的余额单列。跟进回复和预计日期不会写入财务到账。
- 采购审批可在「系统管理 → 字典与口径」将已核对的实际模板登记到 `approval_template`，键为企业微信模板 ID，值为 `{"key":"procurement","fields":{"采购金额":"amount","项目编号":"project_code","发生日期":"expense_date","用途":"reason"}}`。控件标题按真实模板替换。审批通过按已有报销归集服务一次登记为采购，项目匹配失败交财务核对，不作为实际付款；已登记审批状态或字段变更进入差异核对。启用前请财务确认口径并用一份已授权样单验证。
