# 企业微信 CLI 个人连接

小聚现支持企业微信官方 `@wecom/cli@1.3.4`。官方仓库：[WecomTeam/wecom-cli](https://github.com/WecomTeam/wecom-cli)，命令与授权说明：[CLI reference](https://github.com/WecomTeam/wecom-cli/blob/main/docs/cli-reference.md)。依赖已锁定在 `backend/agent_runtime`，Docker 会按服务器平台安装对应二进制。

## 当前接入范围

- 个人 CLI 扫码绑定与公司自建应用授权分别管理。绑定 CLI 后可按该机器人实际授权处理文档、表格、待办、日程、会议等业务；公司审批、财务、员工网页登录仍走各自的数据源与授权。
- 已读取官方返回的 15 类服务、163 项方法目录。目录中排除了直接上传、下载、导入等本机文件方法，当前可登记 149 项候选业务动作；实际执行还会校验方法参数、资源权限和功能授权，目录可见不等于全部功能已授权。
- 查询通过官方 CLI 实际执行，结果标为「企业微信真实数据 · 个人授权」。新增、修改、发送、删除等操作统一进入现有确认单流程，本人确认后提交。
- 文件路径参数需要专用的本人附件适配，目前不会让模型构造任意服务器文件路径。现有工作台业务附件入口仍可照常使用。

## 使用

打开小聚，可以说：

- “查询我在企业微信里的待办。”
- “在企业微信文档里搜索项目周报。”
- “查看我本周的企业微信日程。”
- “在企业微信创建一份项目周报文档。”随后核对确认单。

平台返回 `851008` 时表示机器人尚未获准使用对应功能。小聚会展示企业微信官方授权入口；平台允许机器人创建者自行开通时，可通过该入口完成。需要机器人管理员处理的情况会保留明确提示。带授权参数的链接只显示在本人任务界面，不发给模型。

## 按账号保存

每位员工的连接目录为：

```text
<STORAGE_DIR 父目录>/xiaoju/wecom-cli/<平台用户 ID>/
  binding.json        # 所属账号、连接版本、官方服务目录，不含密钥
  config/
    credentials.enc  # 官方 CLI 加密凭证
    .encryption_key  # 无系统 keyring 时使用的加密密钥
  schemas/            # 按方法缓存参数定义
  work/               # 该账号的独立工作目录
```

凭证文件均为 `0600`。绑定有两种方式：员工在小聚里自助扫码（推荐），或运维在受控服务器导入该账号的已授权配置；凭证不提交 Git、不放入聊天。

## 自助绑定

员工在小聚首页点「绑定我的企业微信」，服务端为该账号起一次官方 CLI 扫码会话：二维码写入该账号自己的 `.bind/work/qr.png`，前端每 2.5 秒轮询状态；员工确认后服务端校验 `auth show --status`，把会话目录里的 `config/` 整体落位到该账号的 `config/`，生成 `binding.json`，再清理临时目录。

- 会话 5 分钟过期；关闭弹窗即取消并清理，不留半份凭证。
- 一个账号同时只有一个扫码会话；已绑定的账号需先「解除绑定」才能重绑。
- 解除绑定只删除本人目录（`DELETE /assistant/wecom-cli/binding`），不影响其他账号。
- 扫码授权的是企业微信机器人，能力范围仍受机器人功能授权（`851008`）约束。

## 个人数据同步

绑定后系统把本人授权范围内的数据拉取到本地快照表 `sys_wecom_item`，按 `(用户, 服务, 外部 ID)` 幂等更新；`preferences` 不参与，管理员也读不到他人内容。

- **频率**：绑定成功立即同步一次，此后每 10 分钟增量刷新；个人中心可手动「立即同步」。
- **当前覆盖**：待办（`todo.list`）、日程（`calendar.schedules.list`，前后 7/30 天窗口）。
- **待办范围**：接口返回的是"机器人为创建人、对话人为参与人"的待办，不是成员在企业微信里的全部待办，界面按实际返回展示。
- **待开通**：文档搜索、邮件搜索需要机器人功能授权（`851008`），授权后在 `wecom_sync_service.PULLERS` 增加对应拉取器即可，表结构不用改。
- **聊天记录**：需要企业开通「会话内容存档」，普通应用拿不到，属于合规与付费能力。

企业微信对个人数据**没有服务端推送**，因此这里的"实时"是分钟级：通讯录这类企业级数据走回调可以做到秒级，个人空间数据只能轮询。

生产环境中，仍使用公开演示密码的账号不能访问个人 CLI 数据。先在「个人中心 → 修改密码」设为自己的密码，再由运维完成该账号连接的部署。修改密码会撤销旧登录令牌；正在运行的旧任务也不能继承修改后的账号权限。

首次给账号添加个人 CLI 连接后，旧版登录令牌需重新登录。查询、确认、历史结果和连接状态都按登录账号隔离；连接版本变化会使旧确认单失效。
