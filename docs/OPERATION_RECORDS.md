# 操作记录

在「权限配置 → 可见菜单」勾选“操作记录”后，获授权账号可在「报表与记录 → 操作记录」查看全站记录，可按账号、模块、日期、来源、结果筛选和导出索引，展开每条操作可看字段修改前后内容。平台管理员始终可查看；未授权账号不能查询、导出或查看详情。该权限独立于系统管理，不会授予更改员工权限的能力。界面上报只允许当前已认证账号，不能指定操作人。

启用以后记录工作台接口调用、登录退出、页面访问及按钮操作、系统任务和 MCP 工具执行。界面事件明确标记为客户端上报；数据库触发器在原业务事务中捕获新增、修改、删除，包含批量 SQL。同一次请求以独立标识串联，账号姓名和标识保留当时快照；无账号上下文的数据库连接单独标识，不推断成人工操作。

成功、失败、权限拒绝和已跳过分开记录。业务回滚不会留下已提交修改；若一次请求先提交了部分数据再失败，则保留失败结果及确实已提交的变化。日志不能通过工作台修改或删除。密码、令牌、应用密钥以及手机/证件等字段在入库前隐藏或遮盖。

既有操作审计、智能工具审计及任务执行记录按原有证据保留为历史记录，未记录的账号快照、结果或字段不补造。企微原表由外部人员编辑后，只记录工作台读取到的同步变化；没有原表作者证据时不会将读取账号冒充成原表编辑人。

新增业务表在启动时补装触发器。请求审计临时写库受阻时先存服务器私有补录目录，启动时及每分钟补录；业务行变更记录始终与业务事务一起提交或回滚。日志数据在数据库备份中一起保留。
