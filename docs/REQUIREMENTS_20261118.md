## 后续企微出库接入

按用户本次决定，暂不绑定未知审批模板或补造公司库存。一键报警当前可手工入库、出库和报废；学校采购可自动形成入库。企微审批接收和定时兜底已准备好，收到真实模板、字段及授权后再配置。

配置入口是「系统管理 → 字典与口径 → 企微审批模板映射」。键为真实模板 ID，值示例：

```json
{
  "key": "stock_out",
  "fields": {
    "运营项目编号": "project_id",
    "产品编号": "product_id",
    "出库数量": "quantity",
    "学校编号": "school_id",
    "业务日期": "occurred_on",
    "出库说明": "note"
  }
}
```

前三个字段必需，学校、日期和说明可选。审批申请人须为本项目有效执行成员并获仓库查看权限；只有审批通过才出库。已入库审批若撤销或内容变化会转人工核对，不自动篡改既有库存记录。回调和定时兜底共用幂等处理；兜底拉取还需企微审批接口授权及 `APPROVAL_RECONCILE_ENABLED` 配置。
