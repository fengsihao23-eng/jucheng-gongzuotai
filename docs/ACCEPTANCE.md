## 全链路验证（PPT 核心命题）

- **审批通过即登记**：模拟企微合同审批 → 生成与企微一致的 AES 加密回调 → POST `/api/v1/wecom/callback`（验签、解密）→ 合同台账自动登记。实测 237ms，重复推送 3 次只登记 1 条；看板签约额实时 +¥1,380,000；营销管控与领导收到企微推送。
- **费用报销 → 项目归集 → 报表生成**：报销单带「所属项目」自动归集；缺项目进入待归集池；同一单据在日支出报表和周利润表中金额一致。
- **银行流水半自动登记**：520 行网银流水 161ms 解析入库，重复导入新增 0 条；核对工作台给出匹配建议（金额 + 对方名称，置信 100），确认后自动写出纳日记账与回款。
- **合同归档读取回款**：上传合同 docx，自动解析出「预付 30% / 到货 40% / 验收 25% / 质保 5%」四个回款计划阶段。
- **WorkBuddy 一句话**：13 个 MCP 工具全部真实调用成功，报表类工具返回可下载的签名链接；无令牌/错令牌 401，越权角色被拒，三类均写入审计。
