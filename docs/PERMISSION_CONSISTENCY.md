# 权限配置与账号实际使用

保存个人权限后，使用同一套权限计算生成当前账号资料和管理员看到的已生效菜单、操作。未保存的勾选仅为草稿；弹窗下方单列已保存的实际权限及仍需满足的数据条件。

账号在切换页面、重新回到前台或每15秒读取最新权限。同浏览器保存权限时发出同步信号。菜单、按钮和数据范围变化会重新读取当前页面；当前模块权限被撤回时进入无权限页。无需反复退出登录，旧页面也不能继续沿用已撤回的配置。

明确在个人权限中勾选的运营项目入口会显示，即使尚未加入项目。默认普通员工没有参与项目时仍不主动展示入口；进入模块后只返回本人获授权的项目，列表为空时提示加入项目团队。勾选运营入口不自动授予全项目管理权。

对于已在个人权限里授予全公司范围的经营模块，该模块的固定来源业务读取遵循这份明确授权。仅授权项目台账不会开放其他经营模块、原表管理或主动同步。原来的来源白名单仍用于其他读取情形；本人或部门范围若未获来源数据授权，会在管理员的已生效权限说明中展示条件。

2026-11-20 授权调整增加独立工作台使用开关、分组全选与运营功能小项，并按指定名单一次性重置其他账号权限。三位最高权限人员之外，运营项目始终按项目团队隔离；详见[工作台授权与项目隔离说明](ACCESS_CONTROL_20261120.md)。保留名单内人员的原角色和个人授权不重新分配。
