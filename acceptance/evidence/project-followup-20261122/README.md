# 项目跟踪与回款迭代验收

三张需求图共 8 项。本目录保存使用合成业务资料、独立 PostgreSQL 数据库和前端生产构建生成的浏览器截图。桌面分辨率为 1440 × 900，手机分辨率为 390 × 844。

| 需求 | 实际验收操作 | 截图 |
| --- | --- | --- |
| 重点项目看板 | 从看板新建项目，打开任务，提交进展并核对下次反馈日。周月报操作集中在报告页签。 | [新建项目](screens/01a-重点项目新建.png) · [负责人、阶段节点和反馈](screens/01b-重点任务节点反馈.png) |
| 运营项目留言 | 在任务中发送留言，打开过程记录，核对留言正文、作者、时间和原任务安排。 | [任务过程记录](screens/02-留言归入过程记录.png) |
| 各类项目跟踪反馈 | 分别在商机、招标和在建项目中提交进展与下一步。一般项目记录下次跟进日期，经营业绩合同可进入回款执行记录。 | [商机](screens/03a-商机项目跟踪.png) · [招标](screens/03b-校园设备招标跟踪.png) · [在建](screens/03c-信息教室设备安装跟踪.png) · [一般项目](screens/03d-一般项目跟踪.png) · [合同](screens/03e-合同执行跟踪.png) |
| 运营项目综合汇报 | 选择报告周次，核对该周登记的 3,650.50 元收入、现场进展和任务，保存报告版本。 | [运营综合汇报](screens/04-运营综合汇报.png) |
| 小聚逐笔回款汇报 | 在回款页发起汇报，核对小聚答复中的 4 份合同、本月到账金额、跟进情况和未收原因。 | [小聚汇报](screens/05-小聚逐笔回款汇报.png) |
| 合同到期未收提醒 | 执行隔离环境的定时作业，检查负责人站内通知。负责人在手机填写未收原因后提交，清单显示今日已反馈。 | [到期未收清单](screens/06a-合同到期提醒.png) · [手机填写原因](screens/06b-手机提交未收原因.png) |
| 当月回款 | 从回款首页核对本月 3 笔实际到账，合计 25,000.00 元。切换未收合同后核对已结清项目已移出该清单。 | [回款首页](screens/07a-当月回款与预估.png) · [到账清单](screens/07b-当月实际到账清单.png) |
| 待开拓学校任务卡 | 在手机查看待开拓学校的负责人、最近实际跟进和下次日期，点击卡片进入学校跟进档案。 | [待开拓学校](screens/08-待开拓学校任务卡.png) |
