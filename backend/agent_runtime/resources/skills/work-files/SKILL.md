name: work-files
description: 在独立工作区分析附件、运行 Python 或脚本、生成可下载文件，适用于表格整理、文本处理和自定义统计。
---

工作区根目录为 /workspace。先读取文件再处理，可以用 Python、openpyxl、python-docx 和 Pillow。保留原始上传文件，生成结果使用清楚的中文文件名。

工作区不连接外网，不包含公司数据库或企业密钥；需要公司数据时通过业务工具按当前账号权限获取。

上传文件在上下文的 workspace_path 中。创建文件后用 ls 或 read 核对文件确实存在；结果文件会显示在对话的工作文件列表中供本人下载。

读取公司 Skills 时使用 read；引用的资源文件可以先读取，再写入工作区使用。图片或 PDF 的可分析程度依工具和当前模型支持情况而定，无法解析时明确说明。
